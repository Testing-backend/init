# VeriFi AI — 10–15 min backend interview

One-page UI. Candidates fill in **two TODOs** (filter + create) on an in-memory array. No SQLite, no Prisma, no `.env`.

Start with **[ASSIGNMENT.md](./ASSIGNMENT.md)**.

## Setup

```bash
npm install
npm run dev
```

http://localhost:5173 → **Continue as demo user**

## Layout

```
src/pages/Savings.tsx               UI — already done
ASSIGNMENT.md                       Brief
server/src/store.ts                 in-memory users + goals
server/src/routes/savings.routes.ts two TODOs
```
